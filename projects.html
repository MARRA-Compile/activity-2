Team Development Projects

Milestone 1: Site Structure & Navigation

Built the shared HTML skeleton, header, and navigation used across every page.

  1. Draft the site map (Home, About, Schedule, Projects, Contact).
  2. Create identical head metadata for every page.
  3. Build the shared header and navigation bar.
  4. Test navigation links across all pages.

Milestone 2: Styling & Responsive Layout

Applied a consistent visual identity and made the site usable on mobile devices.

  1. Choose a color palette and typography.
  2. Write the shared stylesheet (style.css).
  3. Add responsive rules for smaller screens.
  4. Review styling consistency on every page.

Milestone 3: Interactive Contact Form

Developed the feedback form and its client-side JavaScript behavior.

  1. Design the form fields and layout.
  2. Add labels and accessibility attributes.
  3. Write JavaScript to handle form submission.
  4. Test the form on desktop and mobile browsers.

Milestone 4: Content & Final Review

Filled in page content, the schedule table, and completed a final team review.

  1. Write bios and page copy.
  2. Populate the schedule table with merged cells.
  3. Proofread every page for errors.
  4. Present the finished site to the class.
